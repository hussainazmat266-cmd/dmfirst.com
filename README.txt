DMFirst-style local prototype
==============================

This package is a non-cash UI/game prototype based on the supplied screenshots/video.

Included:
- Home catalogue with Popular, WinGo, Sports, Slots-style sections
- WinGo 30 Sec points-only round + countdown + local results
- Bingo demo
- VIP levels
- Lucky Wheel with demo points
- Aviator/Cricket/Mines/Slots/Fishing/Racing demo screens
- Account, Activity and Promotion pages
- LocalStorage state so demo points/history persist in the browser
- Responsive mobile/desktop layout

Important:
- No real-money betting
- No UPI/payment gateway
- No deposits or withdrawals
- No cash payouts
- No external backend
- No real gambling logic

Run:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Everything runs locally; no server is required.
